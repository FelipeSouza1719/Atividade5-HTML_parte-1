# 🕹️ GameZone Retro

> **A Melhor Loja de jogos que existe!**

A **GameZone Retro** é uma página web dedicada ao catálogo e divulgação de consoles clássicos e jogos retrô, permitindo que os entusiastas de videogames antigos confiram a disponibilidade e os preços de títulos icônicos.

---

## 🚀 Funcionalidades

- **Catálogo de Consoles:** Exibição em lista dos sistemas disponíveis na loja.
- **Tabela de Preços:** Relação direta de jogos, seus respectivos consoles e valores de venda.
- **Links Externos:** Integração com redes sociais (Instagram) para consulta de preços adicionais.

## 📦 Como Executar o Projeto

Para visualizar a página localmente em sua máquina, siga os passos abaixo:

1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd gamezone-retro
   ```
3. Abra o arquivo `index.html` em qualquer navegador web de sua preferência.
